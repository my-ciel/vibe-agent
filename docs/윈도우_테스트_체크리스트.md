# 윈도우 테스트 체크리스트

개발은 리눅스에서 했기 때문에 아래 항목은 **윈도우에서 직접 확인이 필요**합니다. 문제가 있으면 항목 번호와 화면(또는 검은 창의 내용)을 알려주세요.

## 0. 준비
- 깨끗한 윈도우 10/11 PC (파이썬이 없는 상태가 가장 좋아요)
- 한글 사용자 이름 폴더(예: `C:\Users\홍길동\`)에서도 한 번 시험하면 좋아요
- 테스트용 OpenRouter 키 (한도 $1 정도)

## 1. 설치/실행
| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | ZIP 받아서 압축 해제 → `run.bat` 더블클릭 | SmartScreen 안내가 나오면 "추가 정보 → 실행"으로 진행 가능 |
| 2 | `Install uv now?` 에 Y | uv 설치 후 이어서 실행됨 (두 번째 실행부터는 이 질문이 없음) |
| 3 | 첫 실행 | 1~3분 뒤 브라우저가 자동으로 열리고 앱이 보임 |
| 4 | 두 번째 실행 | 몇 초 안에 열림 |
| 5 | 검은 창 닫기 | 앱이 꺼지고 브라우저는 연결 끊김 표시 |
| 6 | 같은 PC에서 앱을 두 개 실행 | 두 번째는 다른 포트(8502 등)로 열림 |

## 2. 자가진단
`run.bat --check` 를 실행하고 **출력 전체를 복사**해 주세요. 모든 항목이 ✅ 이면 정상입니다. (폴더 선택창(tkinter)은 ⚠️ 여도 괜찮아요)

## 3. 앱 기능
| # | 확인 | 기대 결과 |
|---|---|---|
| 7 | 키 입력 → "키 확인" | `키 확인 완료 · 남은 한도 $…` |
| 8 | `📂 폴더 선택…` | 폴더 선택창이 뜨고 선택 후 경로가 입력됨 |
| 9 | 한글이 들어간 폴더 경로 지정 | 오류 없이 연결됨 |
| 10 | "hello.py를 만들고 실행해서 한글 '안녕하세요'를 출력해줘" | 승인 카드 → 승인 → 명령 결과에 **한글이 깨지지 않고** 표시 |
| 11 | "계속 대기하는 명령(예: `ping -t localhost`)을 실행해줘" | 제한시간(기본 60초) 후 중단되고 앱이 정상 유지 |
| 12 | 작업 폴더 밖 파일 읽기 요청 (예: `C:\Windows\win.ini`) | 거절 메시지 |
| 13 | 승인 카드에서 🚫 거절 | 파일이 만들어지지 않고 에이전트가 다음 행동을 물어봄 |
| 14 | 세션 최대 비용을 `0.001`로 두고 요청 | 한도 도달 안내 후 멈춤 |
| 15 | 폴더에 메모장으로 만든 `.txt`(ANSI/cp949) 파일이 있을 때 "이 파일 내용을 읽어줘" | 한글이 정상 표시 |
| 16 | 다른 PC에서 `http://내PC주소:8501` 접속 시도 | 접속되지 않음 (localhost만 허용) |

## 4. 알려진 미확인 사항
- `run.bat`의 uv 설치 경로 처리(`%USERPROFILE%\.local\bin`)와 PowerShell 실행 정책 환경
- 명령 실행 시 `chcp 65001` 처리와 `taskkill` 프로세스 종료
- 학교/회사 PC의 보안 프로그램 또는 네트워크 차단
