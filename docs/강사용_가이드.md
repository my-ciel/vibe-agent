# Vibe Agent 강사용 가이드

## 1. 수강생별 키 발급 (비용 통제의 핵심)

수강생마다 **한도와 만료일이 있는 OpenRouter 키**를 발급하세요. 앱의 "세션 최대 비용"은 보조 장치이고, 실제 방어선은 키 자체의 한도입니다.

### 방법 A: 대시보드에서 한 개씩
OpenRouter → Settings → Keys → Create 에서 이름, Credit limit(USD), Expiration을 지정합니다.

### 방법 B: 스크립트로 일괄 발급
1. <https://openrouter.ai/settings/management-keys> 에서 **관리용(Management) 키**를 만듭니다. (만료일 설정 권장. 이 키는 호출에는 못 쓰고 키 관리에만 쓰여요)
2. 수강생 이름을 한 줄에 하나씩 적은 `names.txt`를 준비합니다.
3. 실행:
   ```
   # 윈도우(cmd)
   set OPENROUTER_MANAGEMENT_KEY=sk-or-v1-관리용키
   uv run python tools/issue_keys.py --names names.txt --limit 3 --days 3 --prefix 11월반 --out keys.csv
   ```
   먼저 `--dry-run`으로 계획만 확인할 수 있어요.
4. 만들어진 `keys.csv`(엑셀로 열림)에 수강생별 키가 있습니다. **발급 시점에만 볼 수 있으니** 안전하게 보관하고, 수강생에게 개별로 전달한 뒤 파일은 지우세요.

> 스크립트는 OpenRouter 공식 문서의 `POST /api/v1/keys`(name, limit, expires_at) 명세대로 만들었고 모의 응답으로 테스트했습니다. 관리용 키가 필요해서 실제 발급은 아직 시험하지 못했으니, 처음에는 이름 1~2개로 `--dry-run` 후 소수만 발급해 확인해 보세요.

### 한도 권장
- 단순한 코딩 과제 1건은 대략 $0.001~$0.01이었어요(저렴한 모델 기준, 개발 중 시험값).
- 대화가 길어지면 매 요청마다 이전 내용을 다시 보내므로 비용이 늘어납니다.
- 1~3일 실습이라면 **키당 $2~5** 정도로 시작해 보고 첫 수업 후 조정하세요. 계정에 크레딧이 충전되어 있어야 합니다.

- **GPT-5.6 Luna**: 균형형(약 $0.008)

- 모델 가격과 종류는 자주 바뀝니다. 학기 전에 한 번 점검하세요.

### 수업용 추가 지침 (`instructions.md`)
앱 폴더의 `instructions.md`에 적은 글이 모든 수강생의 에이전트에게 추가 지침으로 전달됩니다. 예: "코드를 쓸 때마다 이유를 2~3줄로 설명", "HTML/CSS/JS만 사용", "이번 수업 주제는 포트폴리오 페이지". 파일 안의 예시를 참고하세요. (앱 재시작이나 "새 대화" 후 적용)

### 프로젝트 지침 파일 (GEMINI.md 등)
수강생 작업 폴더의 `GEMINI.md`, `AGENTS.md`, `CLAUDE.md`는 에이전트가 **매 요청마다 새로 읽어서** 시스템 프롬프트에 반영합니다. Lab3-2처럼 "GEMINI.md에 규칙을 적고 매 단계 이 파일의 진행 상황을 갱신하라"는 프롬프트가 그대로 동작해요(개발 중 6개 모델 모두 규칙 파일을 만들고 체크리스트를 갱신했습니다). 파일이 길면 파일당 6000자까지만 반영됩니다.

### 가상환경 강제 (패키지 설치는 항상 `.venv`에)
- **지시:** 에이전트는 파이썬 프로젝트에서 패키지가 필요하면 **먼저 `python -m venv .venv`로 가상환경을 만든 뒤** 그 안에만 설치하도록 기본 지시를 받습니다. 가상환경을 언급하지 않은 프롬프트로 4개 모델(Haiku, DeepSeek, Qwen, Luna)을 시험했더니 모두 스스로 `.venv`부터 만들었습니다.
- **차단:** 모델이 어기더라도 작업 폴더에 `.venv`가 없으면 `pip install`, `python -m pip install`, `uv pip install`은 **앱이 실행 전에 막고** "먼저 가상환경을 만들라"고 안내합니다. 전역 파이썬이 오염되지 않아요. (`.venv/bin/pip`처럼 경로를 명시한 명령은 허용)
- 실습 프롬프트에 "가상환경을 만들어줘"가 이미 있는 경우(Lab3-1, Lab4)도 같은 방식으로 동작합니다.

### 백그라운드 실행 (서버, GUI 앱)
`run_command`는 끝나야 결과를 돌려주므로, 계속 실행되는 프로그램은 에이전트가 `start_process`(승인 필요)로 띄우고 `read_process_output`으로 로그를 확인하고 `stop_process`로 종료합니다. 사이드바에 실행 중인 프로그램의 접속 링크와 중지 버튼이 표시되고, 동시에 3개까지 띄울 수 있어요. 새 대화를 시작하거나 앱을 종료하면 함께 정리되고, 비정상 종료로 남은 프로그램은 다음 실행 때 정리됩니다. 에이전트는 서버를 `127.0.0.1`(이 컴퓨터만)로 띄우도록 안내받지만, 모델이 어길 수 있으니 수업에서 한 번 강조해 주세요.

### 파이썬 환경
에이전트가 실행하는 명령은 앱 자신의 환경과 분리되어 있습니다. 작업 폴더에 `.venv`가 있으면 자동으로 활성화된 것처럼 동작하고(`python -m pip install`이 `.venv`에 설치됨), 시스템에 파이썬이 없는 PC에서는 앱이 쓰는 파이썬을 제공합니다. 명령 제한시간은 기본 120초, 최대 900초(패키지 설치용)입니다. TensorFlow처럼 큰 패키지는 파이썬 버전에 따라 설치되지 않을 수 있으니 수업 전에 미리 확인하세요.

### 기본 제공 지침
에이전트는 기본적으로 초보자용 원칙을 따릅니다: 설치 없이 실행되는 단순한 구성(HTML/CSS/JS, 파이썬 표준 라이브러리) 우선, 모호한 요청은 되묻지 않고 가정을 밝힌 뒤 완성된 첫 버전 만들기, 웹앱의 기본 디자인·기능 기준, 끝나기 전 코드 점검, 마지막에 실행 방법과 다음 아이디어 안내.

### `models.json` 편집
`models.json`에서 수강생에게 보여줄 모델을 정합니다.
- `id`는 OpenRouter 모델 페이지의 ID와 **정확히** 같아야 해요. 인터넷이 되면 앱 사이드바가 잘못된 ID나 도구 호출 미지원 모델을 경고합니다.
- 반드시 **도구 호출(tools)을 지원하는 모델**이어야 에이전트로 쓸 수 있어요.
- 수강생이 사이드바에서 "직접 입력…"으로 다른 모델을 쓸 수도 있습니다. 막고 싶다면 알려주세요(기능 추가 필요).
- 모델마다 도구를 쓰는 습관이 달라서, 수업 전에 쓸 모델로 간단한 과제를 먼저 돌려 보세요.

### 첨부 파일(이미지/파일)
- 채팅창에서 이미지와 파일을 첨부할 수 있고, 첨부한 파일은 수강생 작업 폴더의 `attachments/`에 저장됩니다. 이미지는 크기를 줄여(긴 변 1280px) 모델에 전달해서 비용을 줄입니다.
- **이미지를 볼 수 있는 모델만** 이미지를 이해합니다. 기본 목록 중 GPT-4o mini, Gemini 2.5 Flash, Claude Haiku 4.5는 가능하고 DeepSeek Chat, Qwen3 Coder는 불가능합니다. 앱이 선택한 모델 아래에 표시해 주고, 불가능한 모델이면 이미지는 폴더에만 저장하고 안내합니다.
- 이미지는 이후 모든 요청에 계속 포함되므로 대화가 길어질수록 비용이 늘어납니다. 이미지가 필요한 수업이라면 키 한도를 조금 넉넉하게 잡으세요.

## 3. 수업 전 점검
1. 수강생 PC와 같은 환경에서 `run.bat --check`(맥: `bash run.command --check`)를 실행하세요. 한글 경로/출력, 명령 시간 초과, 폴더 밖 접근 차단, OpenRouter 접속을 점검합니다.
2. 강의실 네트워크에서 `openrouter.ai`, `astral.sh`(uv 설치), `pypi.org`, `files.pythonhosted.org`, `github.com`(uv가 Python을 내려받음)에 접속되는지 확인하세요. 막혀 있으면 설치가 실패합니다.
3. 처음 실행은 패키지를 내려받느라 1~3분 걸려요. 수업 시작 전에 각자 한 번 실행해 두게 하면 좋습니다. (미리 한 번 실행하면 이후에는 몇 초)
4. 자세한 윈도우 확인 항목은 `docs/윈도우_테스트_체크리스트.md`를 참고하세요.

## 4. 보안과 한계
- 앱은 `localhost`에서만 열려서 같은 네트워크의 다른 사람이 접속할 수 없습니다.
- API 키는 메모리에만 두고 파일에 저장하지 않습니다. (마지막 폴더/모델만 `~/.vibe-agent/settings.json`에 기억)
- 파일 쓰기와 명령 실행은 **항상 수강생 승인**을 거치고, 파일 접근은 작업 폴더 안으로 제한됩니다. 위험 명령 차단 목록은 실수 방지용 안전망이며 완벽한 보안 장치가 아닙니다. 명령은 승인되면 수강생 계정 권한으로 실행됩니다.
- "파일 수정은 묻지 않고 진행"을 켜면 파일 수정이 자동 승인됩니다(명령은 계속 확인). 초반 수업에서는 끄고 시작하길 권합니다.
- 키가 노출되면 OpenRouter 대시보드에서 해당 키를 바로 삭제하세요.

## 5. 자주 있는 상황
| 상황 | 대응 |
|---|---|
| "크레딧이 부족하거나 한도에 도달" | 수강생 키의 한도 소진. 대시보드에서 한도를 올리거나 새 키 발급 |
| 모델이 도구를 안 쓰고 말로만 답함 | 다른 모델로 바꿔 보세요. `models.json` 조정 |
| 에이전트가 계속 같은 일을 반복 | 사이드바의 "요청당 최대 단계"가 안전장치입니다. 새 대화로 다시 시작하게 하세요 |
| uv 설치가 막힘 | 강사가 미리 uv를 설치해 두거나(`winget install astral-sh.uv`) 네트워크 허용을 요청 |
