# Vibe Agent 시작 가이드 (수강생용)

채팅으로 코드를 만들고 고치는 도우미 앱이에요. 이 컴퓨터에서 실행되고, 만든 파일도 이 컴퓨터에 저장됩니다.

## 1. 준비물
- 인터넷 연결
- 강사에게 받은 **OpenRouter API 키** (`sk-or-v1-...` 로 시작하는 긴 글자)

## 2. 앱 받기
1. GitHub 저장소 페이지에서 초록색 **Code → Download ZIP** 을 누릅니다.
2. 받은 ZIP을 **우클릭 → 모두 압축 풀기**. (압축을 풀지 않고 안에서 실행하면 동작하지 않아요)
3. 풀린 폴더를 찾기 쉬운 곳(바탕화면 등)에 둡니다.

## 3. 실행하기

### 윈도우
1. 폴더 안의 **`run.bat`** 을 더블클릭합니다.
2. "Windows의 PC 보호" 화면이 뜨면 **추가 정보 → 실행** 을 누릅니다. (인터넷에서 받은 파일이라 나오는 안내예요)
3. 검은 창에서 `Install uv now?` 라고 물으면 **Y** 를 입력하고 Enter. 처음 한 번만 나오고 1~3분 걸려요.
4. 잠시 후 브라우저에 앱이 열립니다. 검은 창은 **닫지 말고 그대로 두세요** (닫으면 앱이 꺼져요).

### 맥
1. 폴더 안의 **`run.command`** 를 **우클릭 → 열기** 합니다. (처음에만 필요해요)
2. 열리지 않으면 터미널에서 `bash run.command` 를 실행하세요.
3. 나머지는 윈도우와 같아요.

## 4. 앱 설정 (왼쪽 사이드바)
1. **OpenRouter API 키** 칸에 키를 붙여넣고 Enter → **키 확인** 을 누릅니다. `남은 한도 $…` 가 보이면 성공!
2. **작업 폴더 경로**: 이 앱이 일할 폴더예요. **새 폴더를 하나 만들어서** 그 경로를 붙여넣거나 `📂 폴더 선택…` 을 누르세요.
   - 에이전트는 이 폴더 안의 파일만 읽고 쓸 수 있어요.
   - 중요한 개인 파일이 있는 폴더(문서, 바탕화면 전체 등)는 고르지 마세요.
3. **모델**: 기본값 그대로 시작하면 됩니다. 💚는 저렴한 모델, 🔴는 비싼 모델이에요. 더 다양한 모델은 **🔎 전체 모델에서 찾기**에서 고를 수 있어요. 가격이 낮을수록 결과가 단순할 수 있고, 비싼 모델은 한도를 빨리 써요.
4. **세션 최대 비용 / 요청당 최대 단계**: 강사 안내가 없으면 기본값($1, 20단계)으로 두세요. 한도에 닿아 멈추면 이 칸의 숫자를 올리거나(0이면 제한 없음) 채팅에 "계속해줘"라고 입력하면 돼요. 앱을 다시 켜면 기본값으로 돌아와요.

## 5. 사용하기
아래 채팅창에 만들고 싶은 것을 말해 보세요. 예) *"간단한 할 일 목록 웹페이지를 만들어줘"*

- 에이전트가 파일을 만들거나 고치기 전에 **승인 카드**가 나옵니다. 초록색(+)이 추가되는 내용, 빨간색(-)이 지워지는 내용이에요. 괜찮으면 **✅ 승인**, 아니면 **🚫 거절**.
- 명령을 실행하려 할 때도 승인을 물어봅니다. **무슨 일을 하는 명령인지 모르겠으면 거절**하고 에이전트에게 설명해 달라고 하세요.
- **이미지·파일 첨부:** 채팅창 왼쪽의 **＋** 버튼을 누르거나 파일을 채팅창에 끌어다 놓으세요.
  - 디자인 스크린샷, 오류 화면, CSV·텍스트·코드 파일 등을 보여줄 수 있어요. (이미지는 이미지를 볼 수 있는 모델만 이해해요. 사이드바 모델 아래에 `🖼️ 이미지 입력 가능`이 보이면 돼요)
  - 첨부한 파일은 작업 폴더의 **`attachments/`** 에 저장돼서 에이전트가 프로젝트에서 쓸 수 있어요. (예: 로고 이미지를 웹페이지에 넣기)
  - 이미지를 보낼수록 비용이 조금 늘어요. 한 번에 최대 4장, 파일은 10MB까지예요. pdf·docx 등은 저장만 되고 에이전트가 내용을 읽지는 못해요.
- **대화 목록:** 대화는 **자동으로 저장**돼서 브라우저를 새로고침하거나 앱을 껐다 켜도 이어서 할 수 있어요. 왼쪽 **💬 이 폴더의 대화**에서 **➕ 새 대화**로 새로 시작하고, 이전 대화를 눌러 다시 열고, 🗑로 지울 수 있어요. 폴더마다 대화 목록이 따로예요. 키를 바꿔도 대화는 유지돼요.
  - **공용 컴퓨터라면** 사이드바의 *대화 저장 설정*에서 **💾 대화 기록 저장**을 끄거나, 끝낼 때 **이 폴더의 대화 모두 삭제**를 눌러 주세요. (대화에는 내 코드와 파일 내용이 들어 있어요. API 키는 저장되지 않아요.)
  - 에이전트는 **내가 보지 않은 사이에 바뀐 파일은 덮어쓰지 않아요.** 다른 대화나 내가 직접 고친 파일을 읽은 뒤에만 수정해요.
- **서버·프로그램 실행:** 에이전트가 웹서버 같은 프로그램을 띄우면 왼쪽에 **▶️ 실행 중인 프로그램** 칸이 생기고, **🔗 주소 버튼**으로 바로 열어 볼 수 있어요. 끝내려면 **⏹️ 중지**를 누르세요. 대화를 바꾸거나 새로고침해도 서버는 계속 실행되고, 앱을 닫으면 함께 종료돼요.
- **프로젝트 지침 파일:** 작업 폴더에 `GEMINI.md`(또는 `AGENTS.md`, `CLAUDE.md`)가 있으면 에이전트가 매번 읽고 그 규칙을 따라요. 수업 프롬프트로 만든 규칙 파일이 이 역할을 합니다.
- **가상환경:** "가상환경을 만들고 활성화해줘"라고 하면 작업 폴더에 `.venv`가 만들어지고, 이후 에이전트의 모든 명령에 자동으로 적용돼요. 직접 `activate`를 칠 필요가 없어요.
- 왼쪽 위에서 **사용한 금액**을 볼 수 있어요. 한도에 닿으면 자동으로 멈춥니다.
- 만든 파일은 작업 폴더에서 확인하세요. 웹페이지라면 `index.html` 을 더블클릭하면 브라우저에서 열려요.

## 6. 끝내기
검은 창(터미널)을 닫으면 앱이 꺼집니다. API 키는 컴퓨터에 저장되지 않으니 **다음에 실행할 때 다시 붙여넣어야** 해요.

## 7. 문제가 생기면
**오류는 화면에 원인과 함께 표시돼요.**
- 빨간 상자: 키, 한도, 모델, 네트워크 문제 등이에요. 무엇을 해야 하는지 같이 적혀 있어요. ("모델을 바꿔서 다시 보내거나 새 대화로 시작" 등)
- 에이전트 작업 카드의 **⚠️**(명령이 실패함)와 **❌**(도구 오류)는 **자동으로 펼쳐져서** 오류 내용을 바로 볼 수 있어요. 에이전트가 원인을 설명하고 고쳐 달라고 해도 돼요. ("방금 오류 원인을 알려줘")
- "앱 내부 오류"가 나오면 **오류 자세히 보기**를 열어 내용을 복사해 강사에게 보여 주세요. 같은 내용이 내 계정의 `.vibe-agent/errors.log` 파일에도 기록돼요.

| 증상 | 해결 |
|---|---|
| `Install uv now?` 설치가 실패해요 | 학교/회사 네트워크가 막았을 수 있어요. 검은 창을 강사에게 보여주세요. |
| 브라우저가 자동으로 안 열려요 | 검은 창에 적힌 `http://localhost:…` 주소를 브라우저에 붙여넣으세요. |
| `키 확인`에서 오류가 나요 | 키 앞뒤에 공백이 들어가지 않았는지 확인하고 다시 붙여넣으세요. 계속되면 강사에게 알려주세요. |
| "크레딧이 부족하거나 한도에 도달" | 키의 한도를 다 썼어요. 강사에게 문의하세요. |
| 폴더 선택 버튼이 안 돼요 | 폴더 경로를 직접 붙여넣으세요 (탐색기 주소창을 클릭하면 경로가 복사돼요). |
| 이상하게 동작해요 | `run.bat --check` 를 실행해서 나온 결과를 강사에게 보여주세요. (맥: 터미널에서 `bash run.command --check`) |

## 안전 수칙
- API 키는 **다른 사람에게 보여주거나 채팅·파일에 적지 마세요.**
- 모르는 명령이나 이상한 파일 수정은 승인하지 않아도 됩니다.
- 이 앱이 만든 코드는 틀릴 수 있어요. 실행해 보고 확인하세요.
