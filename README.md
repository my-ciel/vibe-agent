# 🤖 Vibe Agent

**말로 설명하면 코드를 만들어 주는 채팅형 코딩 도우미**예요.
내 컴퓨터에서 정한 폴더 안에 파일을 만들고, 고치고, 실행까지 해 줘요. 쓴 만큼만 비용을 내는 종량제라 구독이 필요 없어요.

> 예) "간단한 할 일 목록 웹페이지를 만들어줘" → 파일이 만들어지고, 서버가 실행되고, 주소를 눌러 바로 확인할 수 있어요.

## 이런 걸 할 수 있어요

| | |
|---|---|
| 💬 **채팅으로 요청** | 만들고 싶은 것을 말로 설명하면 에이전트가 계획하고, 파일을 만들고, 고쳐 줘요. |
| ✅ **항상 승인 후 실행** | 파일을 쓰거나 명령을 실행하기 전에 변경 내용을 보여 주고 허락을 구해요. |
| 📂 **내가 정한 폴더 안에서만** | 에이전트는 작업 폴더 밖의 파일을 읽거나 고칠 수 없어요. |
| ▶️ **프로그램 실행·확인** | 웹서버 같은 프로그램을 띄우고, 주소 버튼으로 바로 열어 볼 수 있어요. |
| 📎 **이미지·파일 첨부** | 디자인 스크린샷, 오류 화면, CSV, 코드 파일을 보여 줄 수 있어요. |
| 💾 **대화 자동 저장** | 새로고침하거나 앱을 껐다 켜도 이어서 할 수 있고, 여러 대화를 오갈 수 있어요. |
| 💰 **사용 금액 실시간 표시** | 쓴 금액이 왼쪽에 바로 보여요. |
| 🐍 **파이썬 환경 자동 처리** | `.venv` 가상환경과 패키지 설치를 알아서 챙겨요. |

## 시작하기

### 1. 준비물
- Windows 10/11 또는 Mac, 인터넷 연결
- **OpenRouter API 키** (`sk-or-v1-...`로 시작해요. 수업에서는 강사님이 나눠 줘요)
- 파이썬은 미리 설치하지 않아도 돼요. 처음 실행할 때 필요한 것을 자동으로 준비해요.

### 2. 받기
이 페이지 위쪽의 초록색 **Code → Download ZIP**을 누르고, 받은 파일을 **우클릭 → 모두 압축 풀기** 하세요.
(압축을 풀지 않고 안에서 실행하면 동작하지 않아요.)

### 3. 실행하기

| | |
|---|---|
| **Windows** | 폴더 안의 **`run.bat`**을 더블클릭하세요. 보호 화면이 뜨면 *추가 정보 → 실행*을 누르고, `Install uv now?`라고 물으면 **Y**를 입력하세요. |
| **Mac** | **`run.command`**를 **우클릭 → 열기**하세요. 열리지 않으면 터미널에서 `bash run.command`를 실행하세요. |

처음에는 1~3분 걸려요. 잠시 뒤 브라우저에 앱이 열려요. **검은 창(터미널)은 닫지 마세요.** 닫으면 앱이 꺼져요.
(두 번째부터는 몇 초면 열려요.)

### 4. 처음 설정하기 (화면 왼쪽)
1. **OpenRouter API 키**를 붙여넣고 **키 확인**을 누르세요. `이 키의 남은 한도 $…`가 보이면 성공이에요.
2. **작업 폴더**를 정하세요. **새 폴더를 하나 만들어서** 시작하는 걸 추천해요. 에이전트는 이 폴더 안에서만 일해요.
3. **모델**은 기본값 그대로 시작하면 돼요.

이제 아래 채팅창에 만들고 싶은 것을 입력하면 돼요.

## 이렇게 써 보세요

**예시 요청**
- "할 일을 추가하고 완료 체크할 수 있는 웹페이지를 만들어줘"
- "방금 만든 페이지에 다크 모드 버튼을 추가해줘"
- "이 오류가 왜 나는지 알려주고 고쳐줘"

**알아두면 좋아요**
- **승인 카드:** 초록색(+)은 추가되는 내용, 빨간색(−)은 지워지는 내용이에요. 괜찮으면 **✅ 승인**, 아니면 **🚫 거절**을 누르세요. 무슨 일을 하는 명령인지 모르겠으면 거절하고 설명해 달라고 하세요.
- **파일 첨부:** 채팅창 왼쪽 **＋** 버튼을 누르거나 파일을 끌어다 놓으세요. 첨부한 파일은 작업 폴더의 `attachments/`에 저장돼요.
- **대화 목록:** 왼쪽 **💬 이 폴더의 대화**에서 새 대화를 시작하고, 이전 대화를 열고, 지울 수 있어요. 폴더마다 목록이 따로예요.
- **실행 중인 프로그램:** 에이전트가 서버를 띄우면 왼쪽에 **🔗 주소 버튼**과 **⏹️ 중지**가 생겨요.
- **프로젝트 규칙 파일:** 작업 폴더에 `GEMINI.md`(또는 `AGENTS.md`, `CLAUDE.md`)를 만들어 규칙을 적어 두면 에이전트가 매번 읽고 따라요.
- 만든 결과물은 작업 폴더에 그대로 있어요. 웹페이지라면 `index.html`을 더블클릭해서 열어 보세요.

## 비용은 어떻게 되나요?

- 쓴 금액만큼 OpenRouter 크레딧에서 차감돼요. 왼쪽 위 **이번 세션 비용**에서 실시간으로 볼 수 있어요.
- 간단한 요청 하나는 보통 1센트 안팎이에요. 대화가 길어질수록 매번 지난 내용을 함께 보내서 비용이 조금씩 늘어요.
- 왼쪽의 **한도**는 두 가지가 서로 달라요.
  - **키 확인 뒤의 남은 한도:** 내 API 키에 정해진 한도의 남은 금액 (확인한 순간의 값)
  - **비용 아래 진행 바:** 이 앱의 *세션 최대 비용* 설정 (0으로 두면 제한 없음)

## 안전하게 쓰기

- **API 키는 다른 사람에게 보여 주거나 채팅·파일에 적지 마세요.** 이 앱은 키를 컴퓨터에 저장하지 않아서, 앱을 다시 켜면 다시 붙여넣어야 해요.
- 앱은 **내 컴퓨터에서만** 열려요. 같은 와이파이의 다른 사람은 접속할 수 없어요.
- 중요한 개인 파일이 있는 폴더(문서, 바탕화면 전체 등)는 작업 폴더로 고르지 마세요.
- **공용 컴퓨터**라면 사이드바의 *대화 저장 설정*에서 **💾 대화 기록 저장**을 끄거나, 끝낼 때 **이 폴더의 대화 모두 삭제**를 눌러 주세요. 대화에는 내 코드와 파일 내용이 들어 있어요.
- AI가 만든 코드는 틀릴 수 있어요. 실행해 보고 확인하세요.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 처음 실행에서 설치가 안 돼요 | 학교·회사 네트워크가 막았을 수 있어요. 검은 창 내용을 강사님께 보여 주세요. |
| 브라우저가 자동으로 안 열려요 | 검은 창에 적힌 `http://localhost:…` 주소를 브라우저에 붙여넣으세요. |
| 키 확인에서 오류가 나요 | 키 앞뒤에 공백이 없는지 확인하고 다시 붙여넣으세요. |
| "크레딧이 부족하거나 한도에 도달" | 내 키의 한도를 다 썼어요. 강사님께 문의하세요. |
| 에이전트가 중간에 멈췄어요 | 사이드바의 *요청당 최대 단계*에 닿은 거예요. 채팅에 "계속해줘"라고 입력하세요. |
| 요청이 거절됐다고 나와요 | 모델을 다른 것으로 바꿔서 다시 보내 보세요. 계속되면 **➕ 새 대화**로 시작하세요. |
| 이상하게 동작해요 | `run.bat --check`(Mac은 `bash run.command --check`)를 실행해서 나온 결과를 강사님께 보여 주세요. |

**"앱 내부 오류"**가 나오면 **오류 자세히 보기**의 내용을 복사해서 강사님께 보여 주세요. 같은 내용이 내 계정의 `.vibe-agent/errors.log` 파일에도 기록돼요.
